### Overview
Tools to help urban planners choose sites and allocate resources. The project combines map data with computer vision on street-level imagery, so sites can be compared on both the street network and the infrastructure that is actually there.

### How it works
- Maps and street networks are built with OSMnx and NetworkX.
- OpenCV analyzes street-level imagery and infrastructure.
- Site selection and resource planning draw on both.

### Tools
Python, OpenCV, OSMnx, NetworkX
