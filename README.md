# paawankdesai.com

Personal site of Paawan Desai, built with Jekyll from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and served by GitHub Pages.

- Pages: `_pages/` (About is `about.md`, plus `cv.md`, `portfolio.html` and `how-i-build.md`)
- Projects: `_portfolio/`. Each one sets `group` (`featured`, `gauntlet` or `earlier`) and `order` in its front matter.
- Navigation: `_data/navigation.yml`. Site settings and the sidebar: `_config.yml`.
- Resume PDF: `files/Paawan_Desai_Resume.pdf`

Run locally with `bundle install` then `bundle exec jekyll serve`.
